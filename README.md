Ductil - Serviços | Landing Page

Uma landing page moderna, responsiva e sofisticada criada para a Ductil - Serviços, uma empresa focada em Desenvolvimento Humano que oferece soluções integradas em Programação, Psicologia e Marketing.

O design foi construído com uma paleta de cores Dark Mode e detalhes em dourado metálico para transmitir elegância, confiança e inovação.

Funcionalidades

Design Premium & Responsivo: Adapta-se perfeitamente a desktops, tablets e smartphones.

Dark Mode Nativo: Fundo escuro com contrastes precisos em tons de dourado e cinza.

Glassmorphism: Barra de navegação com efeito de desfoque (blur) e transparência.

Animações CSS Avançadas:

Esferas flutuantes na seção Hero criando um efeito 3D sutil.

Arte abstrata giratória na seção "Sobre", feita inteiramente com CSS.

Formulário Interativo: Inputs com Floating Labels (rótulos flutuantes) inspirados no Material Design.

Smooth Scrolling: Navegação suave ao clicar nos links do menu.

Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as tecnologias base da web, sem necessidade de frameworks pesados, garantindo alta performance:

HTML5: Semântica e estruturação da página.

CSS3: Estilização, variáveis (Custom Properties), Grid/Flexbox e animações @keyframes.

JavaScript (Vanilla): Lógica para animação do formulário e manipulação de eventos.

Lucide Icons: Biblioteca de ícones leves e escaláveis via CDN.

Google Fonts: Fontes Playfair Display (títulos) e Inter (textos corporais).

Estrutura de Arquivos

/

Como executar o projeto

Como o projeto é construído puramente em HTML, CSS e JS, não é necessário instalar dependências ou usar servidores complexos.

Faça o clone do repositório:

git clone https://github.com/seu-usuario/ductil-landing-page.git


Navegue até a pasta do projeto.

Dê um duplo clique no arquivo index.html para abri-lo no seu navegador de preferência.

Dica: Se estiver usando o VS Code, você pode usar a extensão Live Server para rodar o projeto e ver as alterações em tempo real.
